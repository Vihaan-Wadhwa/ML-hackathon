## 1. Component Overview & Responsibilities

In distributed map-matching, noisy vehicle GPS observations deviate from true physical roads due to urban canyon multipath reflections, signal dropout, and low sensor sampling rates.

**Device 3** is responsible for:
1. **Task 1 — Road Topology & Graph Construction:** Ingesting raw geospatial network data (`.nodes` and `.arcs`), computing physical metric lengths via the spherical Haversine formula, constructing directed NetworkX `MultiDiGraph` networks that preserve parallel edges and one-way constraints, and rendering geographic road network visualizations.
2. **Task 2 (Step 1) — Device 2 ML Output Integration:** Loading candidate road predictions generated by Device 2's classifier in Parquet format, performing referential integrity checks against the trip's road graph, linking GPS trajectory coordinates from `.track`, and normalizing binary match probabilities into categorical emission distributions with temperature scaling.

## 5. Usage & Execution Examples

### 5.1 Building a Road Graph
```python
from pathlib import Path
from graph.graph_builder import build_road_graph

nodes_path = Path("path/to/<trip_id>.nodes")
arcs_path = Path("path/to/<trip_id>.arcs")

# Construct the MultiDiGraph
road_graph, arc_lookup, stats = build_road_graph(nodes_path, arcs_path)

print(f"Nodes: {stats['total_nodes']:,}")
print(f"Arcs:  {stats['total_directed_arcs']:,}")
print(f"Total Road Length: {stats['total_directed_length_m'] / 1000:,.2f} km")
```

### 5.2 Ingesting and Normalizing Device 2 Candidate Predictions
```python
from pathlib import Path
from decoder.candidate_io import load_candidate_predictions, normalize_emission_probabilities

parquet_path = Path("candidate_predictions_sample.parquet")

# 1. Ingest predictions from Device 2
candidates_df = load_candidate_predictions(parquet_path)

# 2. Normalize probabilities per observation (T=1.0)
norm_df = normalize_emission_probabilities(candidates_df, temperature=1.0)

# 3. Optional temperature scaling: T=0.5 (sharpen) or T=2.0 (soften)
sharp_df = normalize_emission_probabilities(candidates_df, temperature=0.5)
```

### 5.3 Generating Road Network Visualizations
```python
from pathlib import Path
from visualization.road_network_plot import visualize_road_graph

out_file = Path("results/my_trip_road_network.png")
visualize_road_graph(road_graph, out_file, title="Trip Road Network")
```

## 8. Device 4 Handoff Interface

Device 4 (Route Evaluation and UI) can consume Device 3's output directly:
```python
from graph.graph_builder import build_road_graph
from decoder.candidate_io import load_candidate_predictions, normalize_emission_probabilities

# 1. Load Road Network
G, arc_lookup, stats = build_road_graph("trip.nodes", "trip.arcs")

# 2. Load and Normalize Emissions
candidates = load_candidate_predictions("candidates.parquet")
emissions = normalize_emission_probabilities(candidates, temperature=1.0)

# 3. Retrieve road segment endpoints in O(1)
u, v = arc_lookup[arc_id]
```
